# RELAY · Emergency Connect

[Open the app](https://atif10ala.github.io/relay-emergency-connect/)

A phone-first UI/UX competition prototype for DPS Modern Indian School, Al Wakrah. Open the link in a browser; no download is required. Home-screen installation is supported through the web app manifest.

## The journey

Choose a floor and help type on the opening screen. Add a block or landmark only if known. Review, send and follow the timeline. Messages and direct calls remain available before staff acknowledgement. Switch to Teacher to see the shared inbox and acknowledge as Mrs. Aditi. Return to Student and confirm adult handover.

Unacknowledged requests demonstrate office escalation after 30 seconds. The threshold is an illustrative design rule, subject to school approval. Demo controls include connection loss and immediate escalation.

## Scope

Requests, messages, teacher pings and escalation stay within one browser session. No real school notification or dispatch system is connected. Ping means an in-app inbox notification, not SMS or WhatsApp. The directory uses a listed school contact; no nearest-teacher or live-location claim is made. Call links open the device dialler. The teacher phone number was supplied with permission for public display.

The self-contained interface can reopen offline after its first successful load through the service worker. Sending needs connectivity. This is not a native App Store application. iPhone frames and the Dynamic Island in the PDF are presentation graphics. Phone layouts were checked at 393 by 852 CSS pixels in a desktop browser; physical iPhone installation was not tested.
